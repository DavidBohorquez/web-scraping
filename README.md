# Algorithms - Master 1 Ynov

Ce dépôt contient les exercices et projets réalisés dans le cadre du cours d'Algorithms du Master 1 à Ynov.

## Objectifs du cours

- Comprendre les concepts fondamentaux des algorithmes et structures de données.
- Maîtriser les techniques de résolution de problèmes algorithmique.
- Appliquer des algorithmes connus sur des cas concrets.
- Analyser la complexité des algorithmes.
- Développer des programmes efficaces et propres.

## Contenu

- Exercices sur les algorithmes de base (tri, recherche, récursion).
- Projets de scraping de données et analyse avec API (exemple : Google Play avec SerpAPI).
- Études de cas sur les graphes, arbres et autres structures.

## Exemples d'exercices

- Récupération et nettoyage de données via une API.
- Analyse statistique des données collectées.
- Implémentation d'algorithmes classiques (tri rapide, parcours en largeur/profondeur).
- Génération de rapports synthétiques à l’aide de modèles de langage.

## Installation

Cloner le dépôt :

```bash
git clone <url-du-repository>
cd <nom-du-dossier>
```

Installer les dépendances (exemple Python) :

```bash
pip install -r requirements.txt
```

## Usage

Lancer les scripts d’exemple dans le dossier `scraping-llm` :

```bash
python main.py
```
